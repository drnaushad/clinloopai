1. Connect your own model

Model setup and Ubuntu connection guide

Start Ollama on your computer with cloud features disabled and allow this website’s exact origin. On shared equipment, ask the owner before changing or restarting Ollama.

OLLAMA_NO_CLOUD=1 OLLAMA_HOST=127.0.0.1:11434 OLLAMA_ORIGINS=https://clinloopai.app ollama serve

This example starts a new instance only when the port is unused. For an existing installation, configure its service rather than starting a second instance. See the Ollama setup instructions.

My Ollama runs on a private Ubuntu server

On your laptop, open a private tunnel to an Ollama instance you control:

ssh -N -o ExitOnForwardFailure=yes -L 127.0.0.1:11435:127.0.0.1:11434 USER@YOUR_SERVER

Use http://127.0.0.1:11435 below. The server still needs the exact website origin allowed and cloud features disabled. Server administrators may have access to its processes and logs.

What stays private here

  • Model calls go only to the loopback address you connect. There is no shared-server fallback.
  • No account, shared patient database, browser storage, history service, analytics or cloud model is used by this page.
  • The current text and response stay in page memory. Disconnecting, leaving the page or 10 minutes of inactivity clears the workspace. Closing a tab is not secure deletion from device memory.
  • Someone using the same unlocked screen, browser extensions, a compromised device or the administrator of your model server may still see data. A private endpoint alone does not prove network isolation.
  • Other ClinLoop pages use a different workspace. This page does not make an existing hospital database private per user, or erase earlier history elsewhere.

Clearing this page does not erase model-server logs or guarantee that an already submitted model job has stopped. Using the public page also requires trust in the website code delivered to your browser.

Browsers may request permission to access your local network or block the connection. Allow access only when you intend to connect to your own model; do not disable browser security. If your browser cannot connect, use your approved local installation.
