Report review

Separate local-model review from an optional external research API. Suggestions never close a follow-up obligation or replace clinician review.

Synthetic reports only in this preview. Hospital use requires an approved local installation with staff sign-in, patient access records, clinician-reviewed rules and clinical validation. A local model connection alone does not meet those requirements.

2. Review source text

These categories organize extraction; they are not validated specialties. This preview accepts typed text or UTF-8 .txt files up to 6000 bytes. It does not analyze medical images, DICOM, waveforms, PDFs or scanned documents.

For hospital PDF, OCR and imaging workflows, use your institution’s approved local installation. The document/imaging workflow overview on this public site is a synthetic demo. Check extraction against every original page before interpretation.

3. Compare each suggestion with the report

Each suggestion includes nearby source text so you can check negation, dates and context. Repeated quotes are marked as ambiguous. Source matching proves that quoted words exist, not that a model’s interpretation is correct. Missing or empty results never mean normal findings or completed care.

Session privacy

This page keeps no saved report history and uses no analytics. Report text, results and the gateway access code stay in page memory; disconnecting, changing pathway, leaving or 10 minutes of inactivity clears them. Clearing does not erase model/provider logs, revoke API credentials or guarantee secure deletion from device memory.

The public website is not a hospital patient database. Hospital care must use an approved on-premises installation with local LLMs and its normal authentication, access recording and audit trail. The research API is a separate synthetic-only service with no connection to hospital records.
