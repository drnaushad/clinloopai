# Report upload compatibility — 5 November 2026

Research-preview release `2026-11-05.reports1` adds a prominent report-upload entry
on Analyse patient. The existing six text categories support laboratory,
radiology, pathology, ECG report text, discharge summaries and other written reports.

UTF-8 CSV, TSV and Markdown now load alongside TXT as original text in browser
memory. Updated personal gateways also support plain Word DOCX paragraphs and
simple tables. The existing PDF, report-photo OCR and DICOM report-document paths
remain available. DOCX rejects unsupported content rather than losing it; complex
Word/legacy/proprietary formats require a complete PDF or text export. No input
file is forwarded to a model by the importer.

Complete-source confirmation, 5 MB file limits, 20 PDF/image pages or frames,
120000-byte extracted preview and 6000-byte complete model input remain explicit.
Original evidence retains its language while English/Korean interface labels change.
Image pixels and ECG waveforms require a separate validated interpretation workflow.

This release is based on main b781a3c and excludes the pending atomic-graph and
model-evidence changes from draft PR 66. It does not change clinical rules or
thresholds, authorize patient use, or establish accuracy across report types.
The public site remains synthetic-only. Personal gateway source must be updated
for Word import; shared model/API services are not restarted by the website release.
