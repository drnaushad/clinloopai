# Traceability: hazard → safety requirement → code → verification

Each safety requirement (SR) is a risk control from the [risk management file](RISK_MANAGEMENT.md).
The code column names the file and the function or setting that implements it; the test column names
the automated tests that verify it. `tests/test_regulatory.py` reads this table and fails if a hazard
has no requirement, a requirement has no test, or a named file, symbol or test does not exist, so the
table cannot drift from the code silently. Format of the cells: `path::symbol`, separated by `<br>`.
